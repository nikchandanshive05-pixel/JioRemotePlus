# JioRemote+

A fast, native Android remote app for **JioAirFiber Set-Top Boxes** (Android TV / Google TV). 
Eliminates the clunky and slow JioHome app navigation with an instant, direct Wi-Fi controller featuring tactile haptics and dual operational modes.

## ✨ Features

### 1. ⚡ Quick / Normal Mode
- **1-Tap App Launcher**: Dedicated instant launch cards for **YouTube**, **JioCinema**, **Disney+ Hotstar**, and **Netflix**.
- **Voice Search Mic**: One-touch voice command triggering Google Assistant on your TV.
- **Direct Text Input**: Built-in keyboard sheet allowing you to type searches, passwords, and URLs from your phone straight to the TV screen without tedious on-screen cursor typing.
- **Essential Controls**: Power, Mute, Volume Up/Down, Back, Home.

### 2. 🎮 Jio Replica Mode
- **Photorealistic Physical Clone**: Designed to look and feel like the original Jio remote control.
- **Tactile D-Pad**: Radial gradient casing with the signature Jio electric metallic-blue ring and central OK button.
- **Volume & Channel Rockers**: Authentic tactile rocker switches (`VOL` and `CH`).
- **Brand Shortcut Pills**: Branded pills matching the physical remote layout.
- **Haptic Feedback**: Tick vibrations on every button click for real physical remote tactile sensation.

---

## 📡 Connectivity
- **Primary**: Android TV Remote Protocol v2 (mDNS discovery + TLS secure commands).
- **Direct ADB Wi-Fi Fallback**: Connects directly to STB IP over port 5555 for instant keyevents, app launches, and text injection.
